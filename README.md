## 🌟 Overview

A futuristic, high-performance **3D interactive portfolio website** engineered with modern WebGL capabilities, dynamic particle physics, cybernetic glassmorphism, interactive code execution consoles, and a full-featured retro CyberTerminal.

Designed and tailored specifically to showcase:
- **Salesforce Cloud Architecture**: Apex Triggers, Lightning Web Components (LWC), Flow Automations, Governor Limit Optimization, and REST integrations.
- **Enterprise Projects**:
  - [`GymFit-Salesforce`](https://github.com/devanshg94500/GymFit-Salesforce) — Comprehensive gym management suite with 12+ Custom SObjects, Apex trigger frameworks, and automated PDF invoicing.
  - [`java-servlets-core-concepts`](https://github.com/devanshg94500/java-servlets-core-concepts) — Production-grade HTTP request handling, session management, and Apache Tomcat architecture.
- **Professional Journey**: Salesforce Developer at **Plus91Labs**, Resolution Specialist at **Amazon**, and Recruiter at **Spectraforce**.
- **Credentials & Badges**: Verified Credly AI & MongoDB credentials, plus comprehensive DSA training.

## 🚀 Key Highlights & Features

1. **Interactive Three.js 3D Particle Cloud**:
   - WebGL particle field that gently moves and reacts to mouse navigation.
   - Fluid camera motions and responsive ambient lighting.

2. **Real Project Showcases & Simulators**:
   - **GymFit Operations Console**: Simulates real-time Apex trigger execution, SOQL governor limit monitoring, and automated PDF invoicing.
   - **Java Servlets Inspector**: Interactive HTTP request/session simulation demonstrating cookie extraction, session invalidation, and servlet context caching.

3. **Retro CyberTerminal (`Ctrl+K` or `` ` ``)**:
   - Interactive CLI shell with preset commands: `role`, `projects`, `skills`, `certs`, `about`, `github`, `contact`, and secret Easter eggs.
   - Full command history traversal with Up/Down arrow navigation.

4. **Audio Feedback Engine**:
   - Synthesizer sound effects using Web Audio API (toggleable in Navbar).

5. **Soft Cybernetic UI & Responsive Layout**:
   - Deep slate/midnight palette (`#04060d`) accented with neon cyan, amber, and emerald highlights.
   - Fully optimized for mobile, tablet, and ultra-wide screens.

## 💻 Local Setup & Development

### 1. Clone the repository
```bash
git clone https://github.com/devanshg94500/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```

### 5. Preview the production build locally
```bash
npm run preview
```
